# Бот «Похудение без тренировок» — инструкция для новичка

Ничего программировать не нужно — просто следуйте шагам по порядку.
Уйдёт примерно 30–40 минут в первый раз.

---

## Что делает бот

1. Пользователь пишет `/start` → бот просит подписаться на бесплатный канал.
2. После подписки → короткая анкета (имя, возраст, опыт, цель).
3. После анкеты → предложение купить гайд за ⭐ Telegram Stars.
4. После оплаты → бот отправляет файл гайда и кнопку с прямой платной ссылкой
   на закрытый канал (оплату звёздами при вступлении принимает сам Telegram,
   в обход бота — бот просто показывает ссылку).
5. Каждый день бот сам готовит пост для бесплатного канала (текст + картинка
   через Gemini) и присылает вам на одобрение. После одобрения — публикует
   его автоматически в заданное время, с кнопкой на закрытый канал.
6. Команда `/post` — публикация любого поста вручную (текст + опционально
   картинка от Gemini + одна кнопка) в любой из двух каналов.

---

## Шаг 1. Создайте бота у @BotFather

1. Откройте Telegram, найдите **@BotFather**, нажмите **Start**.
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** — длинную строку вида `123456:ABC-DEF...`.
   Сохраните его, он понадобится на шаге 4. **Никому его не показывайте.**

---

## Шаг 2. Создайте два канала

Если каналы уже есть — просто пропустите создание.

1. Создайте **бесплатный публичный канал** (например `@my_freebie_channel`) —
   на него будут подписываться перед анкетой.
2. Создайте **закрытый (приватный) канал** — туда будут попадать те, кто
   оплатил подписку.
3. **Добавьте вашего бота администратором в оба канала** (Управление каналом →
   Администраторы → Добавить администратора → выберите бота).
   Без этого бот не сможет проверять подписку и создавать ссылки-приглашения.

### Как узнать ID канала

1. Перешлите любое сообщение из канала боту **@userinfobot** (или **@getidsbot**).
2. Он покажет ID вида `-1001234567890` — это и есть `FREE_CHANNEL_ID` /
   `CLOSED_CHANNEL_ID`.

### Как узнать свой ID (для ADMIN_ID)

Напишите **@userinfobot** — он покажет ваш личный ID.

## Шаг 3. Загрузите код на GitHub (без установки программ)

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **New repository**, придумайте название (например `weightloss-bot`),
   оставьте **Private**, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите туда **все файлы из этого проекта** (кроме `.env`, если вы его
   создавали — он не должен попасть на GitHub).
5. Нажмите **Commit changes**.

---

## Шаг 4. Разверните бота на Railway

1. Зайдите на [railway.app](https://railway.app), зарегистрируйтесь через GitHub.
2. Нажмите **New Project → Deploy from GitHub repo** → выберите ваш репозиторий.
3. Railway сам определит, что это Python-проект (по `requirements.txt`).
4. Откройте вкладку **Variables** и добавьте переменные (кнопка **New Variable**):

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `FREE_CHANNEL_ID` | ID бесплатного канала, например `-1001234567890` |
   | `FREE_CHANNEL_URL` | ссылка на бесплатный канал, например `https://t.me/my_freebie_channel` |
   | `CLOSED_CHANNEL_ID` | ID закрытого канала, например `-1009876543210` — нужен, чтобы бот мог публиковать туда посты через `/post` (бот должен быть админом канала) |
   | `CLOSED_CHANNEL_URL` | ваша платная invite-ссылка на закрытый канал, например `https://t.me/+HdwKZ_AgxZ05MWFi` |
   | `ADMIN_ID` | ваш личный Telegram ID |
   | `GUIDE_PRICE_STARS` | `250` |
   | `SUBSCRIPTION_PRICE_STARS` | `499` (это только для текста на кнопке — саму цену подписки Telegram берёт из настроек вашего платного канала) |
   | `STARS_HELP_TEXT` | необязательно — свой текст для кнопки «Где взять Stars», например со своей ссылкой на покупку звёзд. Если не заполнять — бот покажет официальный способ (само приложение + fragment.com) |
   | `GEMINI_API_KEY` | ключ от Gemini API (см. шаг 4.1 ниже) |
   | `TIMEZONE` | `Asia/Dushanbe` — часовой пояс для расписания |
   | `PREPARE_HOUR` / `PREPARE_MINUTE` | во сколько бот готовит черновик и шлёт вам на одобрение, по умолчанию `8:00` |
   | `PUBLISH_HOUR` / `PUBLISH_MINUTE` | во сколько бот публикует одобренный пост, по умолчанию `10:00` |
   | `DAILY_CTA_TEXT` | необязательно — свой текст-приглашение в закрытый канал под ежедневным постом |

### Шаг 4.1. Получите ключ Gemini API

1. Зайдите на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Войдите через Google-аккаунт, нажмите **Create API key**.
3. Скопируйте ключ и вставьте в переменную `GEMINI_API_KEY` на Railway.

### Как это работает день за днём

1. В `PREPARE_HOUR` (по умолчанию 8:00) бот сам генерирует текст и картинку
   на сегодня и присылает вам личным сообщением с тремя кнопками:
   **Одобрить**, **Сгенерировать заново**, **Изменить текст**.
2. Если нажали «Одобрить» до `PUBLISH_HOUR` (по умолчанию 10:00) — пост
   опубликуется автоматически в это время. Если одобрили уже после — бот
   опубликует его сразу же.
3. Если к `PUBLISH_HOUR` пост так и не одобрен — публикация в этот день
   пропускается, и бот об этом напишет вам.
4. Хотите подготовить пост раньше расписания — отправьте боту `/post_today`.
5. Команда `/post` — ручная публикация в любой момент: бот спросит канал,
   текст, нужна ли картинка, текст и ссылку кнопки, покажет превью и
   опубликует после вашего подтверждения.

5. Откройте вкладку **Settings → Deploy** и убедитесь, что команда запуска —
   `python bot.py` (Railway обычно берёт её из файла `Procfile` автоматически).
6. Нажмите **Deploy**. Через 1–2 минуты во вкладке **Deployments → View Logs**
   должна появиться строка `Бот запущен, жду сообщения...`.

Готово — можно писать боту `/start` в Telegram.

---

## Шаг 5. Проверьте, что оплата работает

Telegram Stars встроены в Telegram — отдельный платёжный провайдер подключать
не нужно. Просто убедитесь, что:

- на вашем аккаунте Telegram есть звёзды для теста покупки
  (Настройки → Telegram Stars → Купить звёзды), или
- протестируйте с кем-то из знакомых.

После оплаты бот сам пришлёт файл гайда и предложит подписку.

---

## Важные ограничения этой версии (MVP)

- **Хранение данных.** Бот использует простой файл `bot.db` (SQLite). На
  бесплатном плане Railway он может очищаться при пересборке проекта. Если
  начнёте расти — подключите Railway Volume (Settings → Volumes) и укажите
  путь к `bot.db` внутри него, либо перейдите на внешнюю базу (Postgres).
- **Продление и удаление из канала.** Раз закрытый канал — это нативный
  платный канал Telegram, продлением/удалением подписчиков при неоплате
  управляет сам Telegram по своим правилам, а не бот. Это удобнее, чем
  делать вручную, но проверьте в настройках вашего канала (Telegram Stars
  для канала), как именно это настроено — например, доступ к контенту
  канала обычно закрывается сам, если подписка не продлена.

## Если что-то не работает

- В логах Railway (**Deployments → View Logs**) обычно видно причину ошибки —
  чаще всего это опечатка в переменных окружения или бот не добавлен
  администратором в канал.
- Пришлите мне текст ошибки из логов — разберём вместе.
